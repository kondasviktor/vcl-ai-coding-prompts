## Quick start

1. Open [`prompts.jsonl`](prompts.jsonl) or the [HF Space](https://huggingface.co/spaces/kondasviktor/vcl-ai-coding-prompts).
2. Pick a prompt. Replace every `{{PLACEHOLDER}}`.
3. Paste into Claude Code, Codex, Gemini CLI, or Cursor.
4. Optional: copy a starter from [`rules/`](rules/) into your project (`AGENTS.md`, `.cursorrules`, `CLAUDE.md`, or `GEMINI.md`).
